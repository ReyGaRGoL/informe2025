Declaración de accesibilidad

Fondo Lunaria se compromete a garantizar que este micrositio sea accesible para todas las personas, independientemente de sus capacidades. Creemos que el acceso a la información es un derecho feminista fundamental.

Medidas implementadas

  • Skip link: enlace para saltar la navegación al contenido principal al inicio de cada página.
  • Alto contraste: botón en la esquina inferior derecha para activar modo de alto contraste.
  • Reducir movimiento: botón para pausar animaciones en todo el sitio.
  • Tamaño de letra: controles para aumentar y reducir el tamaño del texto.
  • Texto alternativo: todas las imágenes informativas tienen descripciones; las decorativas están ocultas para lectores de pantalla.
  • Navegación por teclado: todos los elementos interactivos son accesibles mediante teclado (Tab, Enter, Escape, flechas).
  • Indicador de foco visible: outline de 3px en todos los elementos enfocados.
  • Lightbox con zoom: las imágenes se pueden ampliar con un clic, con soporte para teclado y gestos táctiles.
  • Semántica HTML: uso de elementos semánticos y roles ARIA donde es necesario.
  • Contraste de color: las combinaciones de texto/fondo cumplen WCAG AA (4.5:1 para texto normal, 3:1 para texto grande).

Estado de conformidad

Este sitio sigue las Pautas de Accesibilidad para el Contenido Web (WCAG) 2.2 en nivel AA. Las auditorías se realizan con herramientas automatizadas (axe-core, WAVE) y pruebas manuales con lectores de pantalla y navegación por teclado.

Dado que el sitio incluye ilustraciones y elementos visuales complejos, algunas imágenes decorativas pueden no tener descripciones extensas. Esto se indica explícitamente mediante aria-hidden="true" en los contenedores decorativos.

Limitaciones conocidas

  • Los mapas interactivos y gráficos complejos pueden no ser totalmente accesibles para lectores de pantalla. Se proporcionan descripciones textuales alternativas.
  • Los contenidos de terceros (videos de YouTube, documentos en FlipHTML5) pueden tener limitaciones de accesibilidad propias de esas plataformas.
